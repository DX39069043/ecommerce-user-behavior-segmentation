# 电商用户行为分层与差异化运营分析

> 面向数据分析岗位的电商用户分层项目。
> 基于用户行为日志，从“用户为什么没有购买 / 已购买用户处于什么状态”出发，构建可解释的用户分层体系，并通过未来月份数据验证分层对后续购买和流失风险的识别能力，最终形成差异化运营策略建议。

---

## 1. 项目概览

### 项目目标

电商用户的行为和购买状态存在明显差异：

* 有些用户浏览、互动活跃，但始终没有购买；
* 有些用户已经购买，并具有较高历史价值；
* 有些高价值用户后续逐渐沉默，存在流失风险。

因此，本项目重点解决两个问题：

1. **如何根据用户行为识别不同的用户状态？**
2. **这些分层能否识别未来更可能购买或流失风险的用户？**

### 项目核心链路

```text
用户行为日志
      ↓
用户级特征工程
      ↓
按购买状态分流
      ↓
可解释用户分层
      ↓
时间外验证
      ↓
运营候选人群
      ↓
基于购买概率的用户排序
      ↓
差异化运营策略建议
```

---

## 2. 核心方法

传统 RFM 直接应用于全部用户时，大量未购买用户会出现 `Frequency = 0`、`Monetary = 0`，容易把不同购买意愿的用户压缩到同一区域。

因此，本项目没有对全部用户直接进行统一 RFM，而是先根据**是否发生过购买**进行业务分流，再在不同状态下使用不同的特征和分层逻辑。

### 未购用户：识别高潜力首购人群

重点关注两个行为维度：

* **Activity**：由浏览页数、有效停留时长、会话数构成，衡量用户主动活跃程度；
* **Friction**：衡量加购但未购买的程度。

通过数据驱动的 GMM 阈值识别：

> **未购买 + 高 Activity + 高 Friction → 高潜力首购用户**

### 已购用户：识别用户价值与行为状态

保留 RFM 的核心思想，并构造连续化价值指数：

$$
Value\ Index =
\log(1+Total\_Spending)
+\log(1+Purchase\_Frequency)
-\log(1+Recency\_Days)
$$

在已购用户内部识别高价值用户，再结合活跃程度和跨月行为进一步区分：

* 深度互动
* 精准直购
* 高价值跨月沉默
* 常规已购
* 普通浏览

---

## 3. 分层结果

| 用户类型        | 核心特征         | 运营方向        |
| ----------- | ------------ | ----------- |
| **普通浏览**    | 未购、购买意向较弱    | 内容种草、行为引导   |
| **高潜力首购**   | 高活跃 + 加购未买   | 首购转化、购物车挽回  |
| **常规已购**    | 已购买、价值一般     | 复购与唤醒       |
| **精准直购**   | 高价值、购买路径直接   | 一键复购、补货提醒   |
| **深度互动** | 高价值、高活跃      | 个性化推荐、会员权益  |
| **高价值跨月沉默**  | 高价值 + 跨月完全沉默 | 老客召回、流失风险预警 |

项目最终形成的业务链路为：

> **用户类型 → 行为特征 → 用户状态 → 运营策略建议**

---

## 4. 时间外验证

为了避免使用同一时间窗口进行“分层 + 评价”导致的信息泄漏，本项目采用：

> **过去行为用于分层，未来行为用于验证。**

同时采用滚动时间窗口进行验证，检验分层是否能够稳定识别未来行为。

### 高潜力首购用户

以 2019-10 → 2019-11 为例：

| 用户群体  |     样本量 |      次月购买率 |
| ----- | ------: | ---------: |
| 高潜力首购 |   5,408 | **13.30%** |
| 普通未购  | 128,519 |  **5.41%** |

购买率相差 **+7.88 个百分点**，滚动验证中 **6/6 个验证窗口方向一致且显著**。

### 高价值跨月沉默用户

对高价值用户进一步观察跨月完全沉默后的购买表现：

> 滚动验证中 **5/5 个窗口均显著更低**，购买率差约为 **-19.9pp ～ -31.8pp**。

说明：

> **“高价值 + 跨月完全沉默”可以作为稳定的后续购买风险信号。**

---

## 5. 从分层到运营

项目没有停留在“给用户贴标签”，而是进一步将分层结果转化为运营候选人群。

例如：

* **高潜力首购** → 加购提醒、价格提醒、首购激励
* **深度互动** → 个性化推荐、会员权益、跨品类推荐
* **精准直购** → 一键复购、补货提醒、简化购买路径
* **高价值跨月沉默** → 老客召回、个性化优惠、历史偏好推荐

同时，使用 Logistic Regression 对已经圈定的目标人群进行**基于购买概率的用户排序**，解决“资源有限时优先触达谁”的问题。

---

## 6. 项目体现的分析能力

本项目重点体现的不是单纯使用多少模型，而是完整的业务分析链路：

* **业务问题拆解**：识别传统 RFM 对大量未购用户区分不足的问题；
* **特征工程**：围绕购买状态构造 Activity、Friction、Value Index；
* **用户分层**：结合业务规则与 GMM 数据驱动阈值进行分层；
* **统计验证**：使用未来月份进行时间外验证，并结合卡方检验判断差异；
* **基于购买概率的用户排序**：使用 Logistic Regression 对目标名单进行进一步排序；
* **业务落地**：将用户类型映射到对应的运营策略建议。

## 9. 局限与下一步

当前项目的验证属于：

> **观察性 + 时间外预测验证**

因此可以证明用户分层与未来行为之间存在稳定关联，但**不能直接证明运营策略本身产生了因果增量**。

如果进入真实业务环境，下一步可以针对目标人群进行随机分组：

```text
目标人群
   ↓
实验组 / 对照组
   ↓
执行差异化运营
   ↓
比较增量转化率
   ↓
评估 ROI
```

通过 A/B 实验进一步验证：

> **“这个用户分层不仅能识别谁更可能购买，而且针对他们实施差异化运营是否真的有效。”**
